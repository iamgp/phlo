# cli_plugin (/docs/python-reference/packages/phlo-openmetadata/phlo_openmetadata/cli_plugin)



CLI plugin for OpenMetadata integration.

This module provides the CLI plugin that registers OpenMetadata commands
with the Phlo CLI framework.

Example:

> > > from phlo\_openmetadata.cli\_plugin import OpenMetadataCliPlugin
> > > plugin = OpenMetadataCliPlugin()
> > > plugin.metadata.name
> > > 'openmetadata'
