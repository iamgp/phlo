# adapters (/docs/python-reference/packages/phlo-nessie/phlo_nessie/adapters)



Engine-specific adapters for optional Nessie integrations.

This package provides adapters that integrate Nessie with specific query engines
like Trino. Adapters configure catalog connections for Iceberg tables backed
by Nessie.

Available adapters:
trino: Trino catalog plugins for Nessie-backed Iceberg.
