# phlo_superset (/docs/python-reference/packages/phlo-superset/phlo_superset)



Apache Superset integration for Phlo.

This package provides integration with Apache Superset for business intelligence
and data visualization within the Phlo data platform.

Example:

> > > from phlo\_superset import SupersetSettings, get\_settings
> > > settings = get\_settings()
> > > print(settings.superset\_port)
> > > 10007
